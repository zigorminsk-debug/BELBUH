# BELHUB 2.0 — исправленная версия

Полностью переработанный нативный GUI для Windows 7–11.

## Запуск

- 64-битная Windows: `BELHUB-2.0-windows-x64.exe`
- 32-битная Windows: `BELHUB-2.0-windows-x86.exe`

Установка не требуется. Распакуйте архив и запустите подходящий EXE.

## Что исправлено

- низкоуровневый экспериментальный интерфейс заменен на полноценный Windows GUI;
- исправлены обработчики кнопок, выбора портала и двойного щелчка;
- ссылки запускаются через стандартный обработчик URL Windows;
- ошибки больше не завершают приложение: они выводятся в окне и журнале;
- сетевая диагностика выполняется в фоне и не блокирует интерфейс;
- добавлены меню, строка состояния, журнал, поиск, категории и панель сведений;
- кнопки АВЕСТ и СОС ведут на официальные ресурсы.

## Безопасность

Программа не читает и не хранит пароли, личные сертификаты или закрытые ключи. Изменение зоны «Надежные сайты» выполняется только после подтверждения пользователя и только в профиле текущего пользователя.
