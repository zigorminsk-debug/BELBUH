# BELHUB 1.0

Нативный каталог государственных порталов Республики Беларусь для Windows 7–11.

## Готовые сборки

- `release/BELHUB-windows-x64.exe` — Windows x64 (рекомендуется)
- `release/BELHUB-windows-x86.exe` — Windows x86

Приложение переносимое: установка не требуется.

## Возможности

- 37 государственных и инфраструктурных порталов по категориям;
- поиск, пояснения и отметка порталов, которым может требоваться ЭЦП;
- запуск в браузере по умолчанию или Microsoft Edge;
- добавление выбранного домена в зону Windows «Надежные сайты» только после подтверждения пользователя;
- диагностика Edge, стандартных каталогов АВЕСТ и HTTPS-доступа к НЦЭУ;
- переход только на официальные страницы загрузки АВЕСТ и инструкцию обновления сертификатов/СОС НЦЭУ;
- приложение не читает и не хранит логины, пароли, закрытые ключи или содержимое токенов.

## Важное ограничение

BELHUB не включает и не распространяет криптографическое ПО третьих лиц. Кнопка «Установить АВЕСТ» открывает официальный раздел загрузок АВЕСТ, поскольку подходящая сборка зависит от выданного комплекта абонента и типа носителя. Кнопка обновления открывает актуальную официальную инструкцию НЦЭУ. Это исключает тихую установку устаревших либо неподходящих криптокомпонентов.

Некоторые старые порталы могут требовать режим Internet Explorer в Edge, AvCMXWebP и настройки, указанные владельцем конкретного портала. Сам Edge IE Mode управляется политиками Microsoft Edge и не должен включаться приложением в обход администратора организации.
