# BELHUB 3.2

[![Build BELHUB](https://github.com/zigorminsk-debug/BELBUH/actions/workflows/build.yml/badge.svg)](https://github.com/zigorminsk-debug/BELBUH/actions/workflows/build.yml)

Мини-приложение для быстрого доступа к государственным порталам Республики Беларусь, сервисам электронной отчётности, ЭДО и электронным накладным.

## Возможности

- каталог государственных порталов по категориям;
- поиск и запуск без дублирования вкладок;
- проверка доступности порталов;
- проверка совместимости браузера;
- инструкции по настройке браузера;
- контакты технической поддержки;
- меню загрузки программных компонентов;
- запуск обновления сертификатов и СОС АВЕСТ;
- запуск Персонального менеджера сертификатов АВЕСТ;
- проверка и запуск AnyDesk для удалённой помощи;
- проверка AvTunProxy перед открытием ФСЗН и регистрации валютных договоров;
- компактный виджет;
- установщик с ярлыками и опциональным автозапуском виджета.

## Структура

- `web/index.html` — основное HTML-приложение;
- `web/widget.html` — компактный виджет;
- `cmd/launcher` — Windows launcher и обработчик протокола `belhub://`;
- `cmd/widget` — запуск виджета в Microsoft Edge App Mode;
- `installer/installer.nsi` — сценарий NSIS;
- `assets` — логотипы и значки.

## Сборка

Требуются:

- Go;
- [`rsrc`](https://github.com/akavel/rsrc);
- NSIS 3.

На Windows запустите:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Результат появится в `dist/`:

- `BELHUB-3.2.exe`;
- `BELHUB-Widget.exe`;
- `BELHUB-3.2-Setup.exe`.

## Автоматическая сборка GitHub Actions

Workflow расположен в корне репозитория: `.github/workflows/build.yml`. Он запускает этот проект из папки `BELBUH-repo/` через `build.ps1`.

Workflow запускается:

- после каждого push в любую ветку, если изменились `BELBUH-repo/**`, `.github/workflows/build.yml`, `docs/**` или корневой `README.md`;
- для pull request в `main` с теми же фильтрами путей;
- вручную через **Actions → Build BELHUB → Run workflow**;
- при публикации тега вида `v*`.

После обычной сборки готовые файлы доступны в разделе **Actions → Artifacts** и хранятся 30 дней.

Для автоматического создания GitHub Release выполните:

```powershell
git tag v3.2.1
git push origin v3.2.1
```

Workflow создаст Release, сформирует примечания и приложит:

- `BELHUB-3.2-Setup.exe`;
- `SHA256SUMS.txt`.

Подробные инструкции для продолжения работы:

- `../docs/CI_AUTOMATION.md` — автоматическая сборка;
- `../docs/PORTAL_LINKS_AUDIT.md` — сверка порталов с BELPORTAL и AvTunProxy.

## Безопасность

Приложение не сохраняет пароли и закрытые ключи ЭЦП. Системные действия выполняются launcher-компонентом только после команды пользователя. Установщики стороннего ПО загружаются по ссылкам, указанным в интерфейсе.
